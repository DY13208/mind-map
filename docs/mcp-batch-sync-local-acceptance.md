# MCP 批量写入、协同同步与冲突保护：本地交付

本文件记录本地代码、隔离数据库、测试图和浏览器验证；代码提交与推送不代表远端部署。验收没有操作远端业务数据库或修改远端部署开关。历史继续沿用房间活动聚合；重绘不创建业务写入。

## 写入与读取契约

- 已知多节点意图使用 `apply_nodes`，最多 100 项；超过 100 项按批调用。成功项在一个事务里提交一个协同修订；全部失败不增加修订。单项 `add_node` 仍是独立提交。
- 更新文字／富文本携带 `expected.uid`、`expected["__fv.text"]`；备注使用 `__fv.note`；超链接地址与标题共用 `__fv.hyperlink`。没有旧版本字段时读取版本为 0。
- 移动携带原 `parent_uid`、`position`。指定相对位置时使用锚点 UID、原父节点、position、before/after；服务端在锁内重算位置。空目标的显式 index 使用 `target_empty:true`；追加可省略 index。
- 删除先调用 `query_nodes`，明确 UID、`scope=self`、`include_subtree_token=true`，携带返回的 `subtree_token`。token 对完整子树排序后的 UID、父节点、位置、node_version 求 SHA256，不使用分页预览或节点数量。
- Direct 和兼容写入执行相同校验。缺少条件返回 `PRECONDITION_REQUIRED`，过期返回 `REPLACE_CONFLICT`；不能验证的兼容路径明确拒绝。业务错误逐项保留，不回滚无关成功项。
- 批次在第一项执行前保存既有目标的起点基线。同 UID 多次修改对同一基线校验；本批成功新建的 UID 可按依赖继续修改。
- 原 operation ID、原内容、原条件、原 base_revision 共同保留。幂等重放先于最新条件检查，不能把网络结果未知当作未写入，也不能自动读取新条件覆盖旧内容。

完整接口说明见 [mcp-collab-write-contract.md](./mcp-collab-write-contract.md)。

## 浏览器行为

提交、协同模型连续应用、画布呈现分别保留修订状态。批次只应用服务端成功子事件，顶层批次复用现有动画帧／后台 50ms 合并调度器；缺口沿用补拉和恢复，不新增整图刷新工具或 AI 任务结束协议。

普通文字、富文本、备注、超链接在打开时建立编辑会话，记录 UID、字段组、版本和草稿。保存使用原条件，按 UID 重新定位。远端数据正常应用；输入法合成期间不保存；旧 ACK 不关闭较新的草稿。冲突与缺少条件进入终态，不自动补条件重试。

冲突草稿复用 `mind-map-local` 的 `drafts` 存储，以用户、房间、UID、字段组、会话隔离；串行写入和会话关闭标记防止旧异步任务覆盖新内容。保存失败保持原输入；已落盘内容可以刷新后查看、复制、查看最新内容，只有成功保存或明确丢弃才清除，不自动写回服务器。没有升级 outbox 数据库结构。

拖拽开始后远端事件更新独立权威模型，画布结构投影暂缓，只保留脏 UID 集合。松手按原结构守卫提交；失效落点取消。最新投影通过原画布树和渲染器恢复，保留个人展开、视口与有效选区，不回放过期结构。无法证明隐藏节点变化与删除目标无关时会保守取消，要求用户核对后重新操作。

- 在实际 Windows 中文输入法下输入、选词、换焦点和保存，覆盖普通文字、富文本、备注与超链接。自动化使用真实 DOM 的 composition 事件，未模拟物理键盘候选窗口。
- 快速重复拖拽、缩放后拖拽、导航到尚未展开的节点、编辑中换房，核对个人视口、选区、草稿所属房间和旧 ACK。ACK／换房／完成水位边界已有自动回归，仍保留人工体验确认。中间运行曾在拖拽准备时未定位到一个已新增节点，后续同场景完整运行通过；没有证据表明数据库丢节点，离屏／懒加载导航列为专项人工复核。

## 数据库与发布边界

本轮不新增服务端字段或表，字段条件使用现有 `data.__fv`，删除校验值按需计算。现有迁移 009／010／011／012 仍须按各自要求核对，隔离库执行所需迁移；其中 009 并发索引不能放在事务内，012 是此前已有的终态回执契约。

另行发布时：核对迁移和实例版本 → 部署支持严格守卫的兼容服务及前端 → 验证事件桥、原生 MCP、三端协同 → 再启用 Direct。旧浏览器／旧 MCP 客户端对受保护修改可能收到 428，需刷新或重连；新增节点仍沿用原契约。

回滚优先关闭 Direct，保留严格写入保护、事件桥、幂等回执和读取恢复能力。不能回退到绕过条件的写入路径，不能清空本地草稿或待确认 outbox。
