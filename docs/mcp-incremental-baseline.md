# MCP 增量写入与协同同步：优化前基线

## 结论范围

这是基于源码提交 `0160b5a774984158829427a7733ac2b7c588e697` 的隔离环境基线。MCP 写入样本、PostgreSQL 事务与缓存观察器覆盖完整；本报告不代表全部性能验收完成。展开/收起的 13 客户端正式样本、持续资源曲线和可见延迟尚未取得。

环境由独立 Compose project `mcp-incremental-test` 启动，使用隔离 PostgreSQL 16、Redis 7 和两个应用实例，没有挂载生产数据。每个写入房间为 6001 节点（1 根、20 个一级分支、每支 299 个子节点）。10 轮分别从相同合成夹具开始，每轮连续调用 100 次独立 MCP `add_node`，没有用批量工具代替单节点调用。13 个真实 Chromium contexts（7 个连 app-a、6 个连 app-b）在写入期间保持在线；导航按每批最多 4 页启动，因此 LCP 数据不是 13 页同时冷启动的数据。

## 浏览器和协同观察

10 轮共采集 130 个页面 LCP：P50 2.780 s、P95 3.880 s、P99 4.020 s；130/130 个客户端均有 LCP 样本。MCP 写入时的 Long Task observer 覆盖 130 个客户端，记录到 0 个长任务。LCP 来自隔离测试房间和每批最多 4 页的启动波次，不代表线上 13 人同时冷启动结果。

CDP WebSocket 指标在 10 轮的浏览器观察中均记录到 `op:event` 数量为 0。每轮观察对象固定为 app-b 的 6 个客户端，因此奇数轮（app-a 写入）是跨实例观察，偶数轮（app-b 写入）是同实例观察，不能把全部轮次称为跨实例验证。远端 marker 被加在根节点末尾；该位置可能因画布裁剪而不渲染。DOM 等待和 viewport 可见延迟样本均为空，故不能据此声称测得远端可见延迟，也不能用 DOM timeout 单独断言客户端权威数据缺失。`op:event=0` 是本轮缺少实时事件通知的直接观测。

正式的 13 客户端展开/收起 P95 没有完成。一次 Branch10 单页诊断验证了真实按钮可展开，并观察到完整299个直接子节点中的27个进入 DOM；节点可能受画布视口裁剪，不能用全局 DOM 数作完整节点数。该单页结果仅验证测量路径，不构成 13 客户端布局基线。早先 Branch2 的并发点击样本存在渲染/点击测量干扰，不计入 P95。一次 Branch10 13 页运行在第 4 个启动波次中途停止，保留的 checkpoint 显示 12/13 页已就绪、browser-13 尚在打开；没有开始交互计时。

资源方面，汇总文件只含测试结束时的 `docker stats` 快照，不是负载期间的均值或峰值；本轮没有持续 CPU/内存采样，因此资源性能门槛仍缺数据。

## 汇总恢复与证据文件

首轮采集有 7 个完整写入轮次；当时第 8 轮因 harness 把浏览器加载后的稳定版本错误地要求等于 seed 版本而中止。浏览器富文本加载可能产生仅规范化 `text/richText` 的初始化操作。修正检查后保留原始失败证据，在同一 run 中以新的房间完成第 8–10 轮；最终汇总对稳定后的 head 计量，没有覆盖先前失败文件。此恢复只修正 harness 的前置条件，未修改业务源码或重放前 7 轮。

原始结果位于 `tests/mcp-incremental/results/`：

- `baseline-0160-20261012-center-retry-v1-summary.json`：本报告的汇总数据。
- `baseline-0160-20261012-center-retry-v1-baseline.jsonl`：warmup、MCP 调用、operation ID、版本和 10 轮原始记录。
- `baseline-0160-20261012-center-retry-v1-app-*.jsonl`：两个实例的 PG/cache preload 样本。
- `baseline-0160-20261012-center-retry-v1-round-*-browser-metrics.json` 和 `...stable-head-r1-round-*-browser-metrics.json`：13 个页面的分轮浏览器指标；失败的首次第 8 轮文件也保留。
- `baseline-0160-20261012-center-retry-v1-postgres-lock-waits.log`：PostgreSQL 锁等待日志。
- `baseline-0160-20261012-center-retry-v1-interactions-branch10-final-checkpoints.jsonl`：停止时的页面初始化现场，不是完整交互结果。
