# 文件知识库批量权限

- 文件夹名称旁常驻「权限」按钮；文件列表操作列也直接显示「权限」。
- 文件夹树支持独立勾选多个节点，勾选不自动选择后代；点击「批量设置权限」处理勾选的文件夹。
- 文件列表勾选后提供「批量设置权限」，范围为当前页；手机端文件复选框常驻显示。
- 弹窗显示全部目标及其中可管理的数量。按组织架构勾选部门、可选包含下属部门，也可点击部门查看并勾选个别成员，或搜索成员补选；已选成员统一预览并去重，可逐人排除。之后可统一设为可查看、可编辑、可管理，或移除直接授权。

每次最多 100 个资源、500 位成员，资源与成员组合最多 5000 项；提交前重新读取各资源的 ACL，再沿用现有 `putGrant` / `deleteGrant` 接口。后端仍逐项检查管理权限，不增加授权旁路。无权管理的项逐项失败，所有者跳过，其它目标继续处理；结果按资源和成员展示成功、跳过或失败。

部门选择会分页读取本次范围内的全部当前成员，跨部门重复成员只授权一次。读取失败或不完整时阻止提交，避免部分部门成员被遗漏。这里只展开为本次逐人授权：之后新增成员不会自动获得权限，离开部门也不会自动撤销已经授予的直接权限。

只操作所选资源和成员的直接授权，其它成员授权保持原状。文件夹按现有规则向下继承，文件的单独设置优先。移除直接授权不会移除继承或团队权限，因此成员可能仍可访问；需要到来源文件夹或团队调整。

本改动仅涉及前端，无需数据库迁移。验证命令：在 `web` 目录执行 `node --test tests/kbBatchPermissions.test.cjs tests/kbOrganization.test.cjs`；实际组件浏览器交互使用受控 API 数据验证，不修改线上权限。
