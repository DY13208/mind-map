## 已实现的修复

- UID 定位的普通节点写入和移动复用 Direct；复杂引用保留可解释的兼容路径。移动保持 UID、子树、附件、超链接和历史关联。
- 单请求最多 100 项批次，独立项部分成功、显式依赖失败、保存点隔离、仅成功项生成事件与逆操作；有修改时仅增加一个版本。
- 操作 ID、业务内容和首次提交版本固定；恢复边界冲突不刷新版本重试。全部失败批次保存终态结果，重放不重做失败项；超时区分结果未知和确定拒绝。
- 事件桥沿持久操作日志补偿，客户端逐版本应用并在成功后推进水位；远端渲染合并与本地输入反馈分开处理，保留懒加载及旧响应防护。
- 附件挂载读回兼容实际 API 的节点数组和旧 UID 映射，校验精确 UID 及稳定字段，保留上传一次和 CAS 行为。
- 补充排队、路径、降级原因、操作关联、事务阶段和采样丢失诊断；不记录正文或认证信息。

工具、重试、部分成功和回滚契约见 [写入契约](./mcp-collab-write-contract.md)。主分支新引入的读取、计数缓存和渲染优化在冲突解决时优先复用，不能重复引入并行机制。
